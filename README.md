# Eye Cursor — 웹캠으로 Windows 커서 이동

일반 웹캠의 양쪽 홍채 위치를 추출하고, 사용자가 바라본 9개 지점으로 보정하여 **기본 모니터의 마우스 커서**를 움직이는 프로토타입입니다. 클릭·스크롤·키보드 입력은 구현하지 않았습니다. Jev/API 키는 필요하지 않습니다.

## 실행

이 PC에는 `.venv`와 모델을 설치해 둡니다. **`start.cmd`를 더블클릭**하세요.

다른 PC에서는 Windows와 Python 3.11을 설치한 뒤 프로젝트 폴더에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1
.\start.cmd
```

1. 카메라를 화면 위쪽 중앙에 놓고, 얼굴과 두 눈이 미리보기에 보이도록 앉으세요. 얼굴 정면에 충분한 조명을 두세요.
2. **시선 보정**을 누르세요. 기본 모니터에 나타나는 9개의 점을 머리를 최대한 고정한 채 눈으로 바라보세요. 약 25~35초가 걸립니다. 초록색은 수집 중이라는 뜻입니다.
3. 보정 완료 후 **커서 시작** 또는 **F8**을 누르세요. 바라보는 위치로 커서가 이동합니다.
4. **F8**으로 시작/일시정지, **Esc**로 즉시 정지하거나 보정을 취소합니다. 다른 앱에 포커스가 있어도 단축키를 확인합니다.
5. 눈을 약 **1.2초 감으면 일시정지**합니다. 재시작은 F8/버튼으로 합니다. 보정과 재시작에는 현재 손 입력이 필요합니다.

일반적인 깜박임 동안 커서는 멈춥니다. 얼굴을 놓치면 즉시 이동을 멈추며, 1초 이상 놓치거나 카메라 응답이 지연되면 일시정지합니다. 머리 위치·거리가 보정 때와 크게 달라져도 정지합니다. 눈 감기 검출은 조명과 눈 모양에 따라 실패할 수 있으므로 Esc도 사용할 수 있습니다.

커서가 너무 흔들리면 ‘커서 안정화’를 오른쪽으로 이동하세요. 안정화를 높이면 반응도 느려집니다. 위치가 계속 어긋나면 다시 보정하세요.

## 한계

- MediaPipe는 얼굴/홍채의 랜드마크를 찾습니다. 그 자체가 화면 시선을 추정하는 모델은 아니며, 이 프로젝트에서 보정 회귀식을 추가했습니다. 전용 시선 추적 장치 수준의 정밀도를 보장하지 않습니다.
- 머리 회전·이동, 안경 반사, 조명, 카메라 위치, 눈의 형태에 영향을 받습니다. **머리를 고정한 상태의 큰 영역 이동**부터 시험해 보세요. 작은 버튼을 정밀하게 가리키는 성능은 사용자 실측이 필요합니다.
- 보정 데이터의 점별 교차 검증으로 매우 나쁜 보정을 거부하지만, 통과해도 실제 정확도를 보장하지 않습니다. 별도 사용성 검증은 아직 필요합니다.
- 기본 모니터만 지원합니다. Windows 보안 화면/UAC 등에서는 동작하지 않을 수 있습니다. 디스플레이 설정을 바꿨다면 앱을 재실행하세요.
- 완전한 손 없는 컴퓨터 조작 도구는 아닙니다. 현재 범위는 커서 이동입니다.

## 카메라 문제

Windows 설정 → 개인 정보 및 보안 → 카메라에서 데스크톱 앱의 카메라 접근을 허용하고, 카메라를 사용하는 다른 앱을 닫으세요.

여러 카메라가 있으면 다음처럼 번호를 바꿉니다.

```powershell
.\start.cmd --camera 1
```

화면 표시·영상 저장·커서 이동 없이 8초 동안 카메라와 얼굴 검출을 점검합니다.

```powershell
.\.venv\Scripts\python.exe app.py --check-camera
```

## 데이터와 구현

실행 중 영상은 로컬 메모리에서만 처리하며 저장하거나 서버로 보내지 않습니다. 초기 설치 시 패키지와 Google의 모델 다운로드에 인터넷을 사용합니다. 보정 데이터는 종료하면 사라지며 다음 실행 때 다시 보정합니다.

- `camera.py`: 별도 스레드에서 카메라/MediaPipe 처리, 최신 프레임 하나만 유지
- `gaze.py`: 눈 너비로 정규화한 양쪽 홍채 좌표, 9점 보정, 좌표 필터
- `app.py`: 한국어 UI, 보정 화면, Win32 커서 이동 및 전역 키 확인
- `tests/`: 가상 데이터 보정/좌표 검증, 실제 커서 대신 모형으로 정지 경로 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
